Personal Income and Expense Tracker

1. Project Overview

The Personal Income and Expense Tracker is a simple, responsive web application developed using HTML, CSS, and JavaScript. It helps users record and manage their daily income and expenses.

2. Technologies Used

- HTML5 – Creates the webpage structure.
- CSS3 – Provides styling and responsive design.
- JavaScript – Handles calculations and user interactions.
- LocalStorage – Saves transaction data in the browser.

3. Features

- Add income and expense transactions.
- View total income.
- View total expenses.
- Calculate available balance.
- View transaction history.
- Search and filter transactions.
- Delete individual transactions.
- Clear all transaction records.
- View monthly summaries.
- Automatically save data using LocalStorage.
- Responsive user interface.

4. Project Folder Structure

Income-Expense-Tracker/
│

5. How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Add income and expense details.
5. View your financial summary and transaction history.

6. Data Storage

The application uses browser LocalStorage to store transaction details. Data remains available after refreshing the page in the same browser, unless the browser's site data is cleared.
